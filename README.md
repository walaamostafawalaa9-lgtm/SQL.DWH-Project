## 🏗️ Data Architecture
The project architecture follows the standard **Medallion Architecture** (*Bronze, Silver, and Gold layers*) to handle raw data ingestion, cleansing, and analytical modeling:
1. **Bronze Layer:** Raw data ingestion from CSV source files (ERP and CRM systems) into staging tables in SQL Server.
2. **Silver Layer:** Data cleaning, removing duplicates, standardizing data types, and combining multi-source data.
3. **Gold Layer:** Business-ready data modeled into a **Star Schema** optimized for analytical queries and performance.
